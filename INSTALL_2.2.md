# БАЗА. Ё. Русский язык 2.2 — установка

Накопительный патч поверх рабочего курса 2.0 (включая изменения 2.1) или 2.1. Не самостоятельный репозиторий. Экспортируйте прогресс, остановите сервер, сделайте копию папки проекта, распакуйте архив с заменой файлов в `D:\Users\User\Desktop\baza-russian`. Не удаляйте `.git`, оригинальный `icons/pushkin-1827.jpg` и другие старые файлы.

```powershell
cd "D:\Users\User\Desktop\baza-russian"
Test-Path .\icons\pushkin-1827.jpg
npm.cmd run pwa:build
npm.cmd test
node scripts/audit-quality.mjs --strict
.\start.bat
```

Проверка портрета должна вернуть True. При ошибке теста или сборки не публикуйте обновление. Пересборка PWA обязательна: индекс и service worker не включены в патч. Проверьте настройки в обеих темах, откройте выпадающий список на телефоне, проверьте новый пошаговый разбор, сохранение самостоятельного ответа и обновление установленной PWA. После успешной приёмки:

```powershell
git status
git add -A
git commit -m "v2.2 - Guided reasoning, writing assessments and dark mode controls"
git push
```

Отчёт `docs/audits/2.2-audit.md`. Не объявлять курс окончательно экспертно принятым: проверены целевые изменения, но не весь репозиторий, все прежние учебные ключи и результаты реального обучения.
