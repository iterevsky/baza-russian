# БАЗА. Ё. Русский язык 2.1 — локальная установка

Накопительный патч поверх рабочей редакции 2.0. Не отдельный полный репозиторий. Сначала экспортируйте прогресс, закройте приложение, остановите локальный сервер и сделайте копию папки проекта. Распакуйте архив с заменой файлов в `D:\Users\User\Desktop\baza-russian`, сохранив оригинальный `icons/pushkin-1827.jpg` и `.git`.

```powershell
cd "D:\Users\User\Desktop\baza-russian"
Test-Path .\icons\pushkin-1827.jpg
npm.cmd run pwa:build
npm.cmd test
node scripts/audit-quality.mjs --strict
.\start.bat
```

`Test-Path` должен вернуть `True`; не удаляйте оригинальный JPEG. Пересборка обязательна: сгенерированные sw.js и runtime-index.json намеренно исключены, поскольку должны учитывать исходный портрет и точные локальные файлы. В среде подготовки 186/187 тестов, единственный непройденный — отсутствующий оригинальный JPEG. Проверьте, что ответ в карточке сохраняется после перехода на другой урок и перезагрузки, рубеж в конце раздела открывается, старая история не исчезла, обновление установленной PWA работает. Не публикуйте без собственной проверки. После приёмки:

```powershell
git status
git add -A
git commit -m "v2.1 - Visual reasoning, foundational explanations and cumulative assessments"
git push
```
