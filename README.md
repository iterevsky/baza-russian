# БАЗА. Базируем. · Русский язык

Учебный прототип v0.6.0. Два урока модуля 07.08, раздельные история, контроль и конспекты, интервальное повторение, экспорт и импорт. Материалы JSON, без сборщика.

## Запуск Windows

Двойной щелчок по `start.bat`. Node.js и npm должны быть установлены; при первом запуске npx может скачать http-server. Адрес http://localhost:8001/. Для остановки Ctrl+C. При ручном запуске в PowerShell: `npm.cmd start`. Тесты: `npm.cmd test`.

## Обновление

Экспортировать прогресс в профиле v0.5.0, остановить сервер, распаковать архив v0.6.0 поверх существующей Git-папки с заменой файлов. Не удалять `.git`. Удалить устаревший `content/catalog.js` (если отслеживается Git: `git rm content/catalog.js`). Не менять порт 8001 или браузер: origin определяет доступ к сохранённым данным. Версия автоматически переносит совместимые результаты прежнего урока в новую схему. Старые экспортные файлы schema 1 можно импортировать вручную. Импорт заменяет весь прогресс после подтверждения. Он не объединяет копии. Сначала сделать экспорт текущего состояния. После локальной проверки: `git add -A`, `git commit -m "Release v0.6.0"`, `git push` (по одной команде).

## Структура

- `index.html`, `src/styles/main.css`: интерфейс.
- `src/app.js`: навигация и представления; `src/core/content.js`, `lesson-view.js`: загрузка и отображение уроков.
- `src/core/progress.js`: схема 2, миграция совместимых записей, импорт, интервалы; `storage.js`: операции localStorage и прежний формат.
- `content/catalog.json`, `content/tips.json`, `content/lessons/*.json`: учебные материалы; `content/ai-goals.js`: цели ИИ.
- `tests/`: автоматические проверки, включая контроллер с имитацией DOM.

## Ограничения

Два черновых урока, не полный модуль. Основное правило второго урока сверено с § 91 академического справочника; полной редакторской приёмки пока нет. Интервалы 1, 3, 7, 14, 30 дней; при ошибке 10 минут, досрочный верный ответ не увеличивает интервал. Повторение отдельно по урокам, без общего межурочного планировщика. Контроль по одной фиксированной серии из шести вопросов: после раскрытия ответов повтор не считается независимой проверкой. Незавершённая серия при смене урока сбрасывается; уже записанные ответы сохраняются. Порог 100%. История отображает последние 20 записей, экспорт включает все совместимые записи. Хранилище localStorage; миграции несовместимых версий содержания, IndexedDB, PWA, офлайн-пакеты, новый банк независимых экзаменов и синхронизация остаются следующими этапами. Не изменять содержание существующих ID до разработки версионной миграции. Не публиковать до согласования. Тесты Node и имитации DOM не заменяют проверку реального браузера и BAT на Windows.
