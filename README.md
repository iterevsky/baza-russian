# БАЗА. Базируем. · Русский язык

Модульная сборка 0.5.0. Учебные материалы перенесены в JSON; отдельный валидатор и шаблон отрисовки. Без зависимостей для самого приложения и без сборщика. Не готовый PWA и не полный курс.

## Запуск

Из папки, где лежит `index.html`, выполнить `npm start` (Node.js и npm; при первом запуске npx может скачать http-server). Открыть http://localhost:8000/ в браузере. Для остановки Ctrl+C. Для тестов `npm test`, установка пакетов не нужна. Открытие index.html двойным щелчком не поддерживается. При обновлении v0.4.0 сохранить тот же браузер, адрес localhost и порт 8000. Сначала экспортировать прогресс. Старые файлы content/catalog.js, content/introductory-words.js, content/lesson-view.js не используются; удалить при обновлении.

## Структура

- `index.html` — оболочка; `src/styles/main.css` — утверждённое направление А+Б.
- `src/app.js` — контроллер, навигация и представления; `src/core/` — проверка, хранилище и генерация запроса ИИ.
- `content/` — catalog.json, tips.json, lessons/introductory-words.json — каталог, хитрости, теория, задания и карточки; ai-goals.js — цели ИИ. src/core/content.js — загрузка и проверка; src/core/lesson-view.js — отображение типизированных блоков.
- `tests/` — автоматические проверки ядра; `docs/` — план следующих шагов.

## Ограничения

В первой сборке только один демонстрационный урок. Остаются локальное хранилище браузера (localStorage), фиксированный контроль из шести заданий, оценки карточек без алгоритма интервального повторения, экспорт без импорта. Прежний ключ хранения сохранён для того же origin; прогресс локального HTML не переносится автоматически на localhost. Не реализованы Service Worker, установка PWA, IndexedDB, версионные пакеты для офлайн, полноценный банк экзаменационных заданий. Нормативная приёмка материала предстоит. UI и контроллер пока частично связаны, это промежуточная архитектура. React/Vite и TypeScript не отвергнуты: решение после проверки необходимости. Не публиковать до проверки и решения владельца.

## Что ещё не универсализировано

Каталог и JSON-загрузчик читают перечень уроков, но интерфейс пока открывает только один демонстрационный урок. Новые ID сохраняются рядом с прежними индексами, полноценное сопоставление истории при смене версий предстоит. Не менять порядок существующих заданий или карточек до миграции. Контроль пока ровно шесть заданий, порог 100%. Статус урока draft. Девять автоматических тестов проходят; браузерный запуск в рабочей среде заблокирован (ERR_BLOCKED_BY_ADMINISTRATOR). Пользователь подтвердил запуск v0.4.0 на Windows, v0.5.0 ещё не проверена на его устройстве.
