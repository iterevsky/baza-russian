## Хранилище (v0.9)

- IndexedDB: база `baza-russian`, версия 1, хранилище `progress`, запись `current`. Снимок схемы 2 и номер ревизии записываются одной транзакцией. Все операции проходят по очереди. Старая копия localStorage не удаляется и не обновляется после миграции.
- При первом запуске проверяется совместимость исходных данных. Запись IndexedDB имеет приоритет; при неудачном переносе исходная копия не заменяется. Резервный режим localStorage допускается только если нет отметки об успешной миграции. При конфликте вкладок запись отклоняется; сохраните экспорт и обновите страницу.
- Если запись не удалась, приложение сообщает об этом; при незавершённой или неудачной записи предупреждает при закрытии вкладки (если браузер разрешает). Импорт ждёт завершения транзакции; до успеха текущий прогресс не заменяется. Экспорт остаётся JSON схемы 2.
- Не очищать данные сайта, не менять origin. Для отката на v0.8 сначала экспортировать прогресс из v0.9: старый localStorage не содержит новых результатов. После отката импортировать экспорт. Перед возвратом на v0.9 снова экспортировать и импортировать актуальный прогресс вручную: IndexedDB не перезаписывается устаревшей копией.
- Сохранность не гарантируется при удалении данных браузера или внезапном отключении питания. Делайте резервные копии. Автотесты хранилища используют имитацию транзакций; тест реальной IndexedDB в браузере обязателен.

## Установка PWA и автономный режим (v0.10)

1. Открыть http://localhost:8001/ через `start.bat` при работающем сервере. Дождаться сообщения «Пакет загружен» или «Автономная версия готова». Если пакет загружен, закрыть вкладку и открыть адрес снова. При наличии кнопки «Установить» можно установить приложение; иначе использовать меню браузера, если оно поддерживает установку. Даже без установки доступен автономный режим в обычной вкладке после активации service worker.
2. После появления «Автономная версия готова» остановить сервер (Ctrl+C). Закрыть и снова открыть приложение или обычную вкладку по тому же адресу. Проверить все шесть уроков, упражнения, карточки и сохранение заметки. Не использовать принудительное обновление Ctrl+F5 для офлайн-проверки: оно может обходить service worker.
3. Для очередного обновления экспортировать прогресс, остановить сервер, распаковать все файлы сборки поверх постоянной папки и запустить `start.bat`. Нажать «Проверить обновления». Когда появится «Обновление готово», завершить занятие, дождаться сохранения, закрыть ВСЕ вкладки и установленные окна русского языка на этом origin. Открыть приложение снова. Проверить номер версии. Не удалять данные сайта ради обновления.

Манифест, собственные иконки Ё, standalone-режим и service worker кешируют весь текущий демонстрационный курс (23 ресурса). Каждый ресурс сверяется по SHA-256 при установке пакета. Неполный или изменённый пакет не активируется. Без принудительного skipWaiting/clients.claim старая версия работает, пока её окна не закрыты. Кеши разделены по адресу и сборке; удаляются только устаревшие кеши русского языка в той же области регистрации. Если отдельный файл исчез из кеша, он восстанавливается с сервера только при совпадении контрольной суммы. Прогресс остаётся в прежней IndexedDB; service worker не меняет её и не кеширует внешние сайты.

После изменения HTML, стилей, JS, учебных JSON, иконок или манифеста требуется пересобрать `sw.js` командой `npm.cmd run pwa:build` и выполнить `npm.cmd test`. Релиз должен содержать все файлы одной версии. `.gitattributes` сохраняет LF для текстовых ресурсов с контрольными суммами. При неполном обновлении восстановить полную сборку на сервере и повторить проверку. Не включать в Git экспорт личного прогресса.

Первичный запуск требует доступного сервера; скачивание http-server через npx при первом запуске может требовать интернета. Внешние ссылки на справочники и сторонний ИИ не работают без сети. Автономный кеш и IndexedDB могут быть удалены браузером или пользователем, резервные копии остаются обязательными. Для телефона требуется отдельный доступный HTTPS-адрес и первоначальная загрузка пакета на устройстве; localhost телефона не является localhost компьютера. Перенос прогресса между устройствами пока только через экспорт/импорт. Публикация приватного репозитория не выполнялась. Поддержка кнопки установки зависит от браузера. Тесты service worker используют имитацию Cache Storage и событий, не заменяют реальную проверку установки и автономного запуска.

## Новые функции

- Память: очередь всех доступных карточек курса, по времени повторения, с названием исходного урока. Можно переключить на текущий урок или все его карточки. Интервалы остались 1, 3, 7, 14, 30 дней; при ошибке 10 минут.
- Контроль: по два варианта A и B по 6 заданий. Старый вариант A и его ID не изменены. Ответы раскрываются после завершения; использованный вариант больше не предлагается как независимый. Черновик сохраняется при выходе и переключении уроков; историю можно открыть из профиля. Порог по умолчанию 100%, настраивается в профиле от 50% до 100% с шагом 5. Статус освоения определяется текущим порогом, критерий каждого экзамена фиксируется при начале и сохраняется в истории. Независимость основана на честном самостоятельном выполнении, не на технической блокировке доступа к подсказкам.
- Практика: добавлены по два задания с выбором одного ответа, прежние задания и ID сохранены. История и конструктор ИИ поддерживают все три типа. Добавлено четыре задания с несколькими ответами. Всего 19 заданий практики и 24 контрольных предложения.

- Работа над ошибками: отдельная серия из заданий, последние ответы на которые неверны. История сохраняется; после правильного ответа задание не попадает в следующую такую серию.
- Печать: теория текущего урока с дополнительными пояснениями и источником; отдельный лист карточек с вопросами и ответами.
- 37 автоматических тестов, включая имитацию интерфейса и service worker; реальная печать и браузер Windows требуют проверки.
