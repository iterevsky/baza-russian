# БАЗА. Базируем. · Русский язык

Учебный прототип v0.7.0. Два черновых урока модуля 07.08, раздельный прогресс, межурочное повторение, по два фиксированных варианта контроля, упражнения с выбором ответа и расстановкой запятых. Материалы JSON, без сборщика.

## Запуск Windows

Двойной щелчок по `start.bat`. Node.js и npm должны быть установлены; при первом запуске npx может скачать http-server. Адрес http://localhost:8001/. Для остановки Ctrl+C. При ручном запуске в PowerShell: `npm.cmd start`. Тесты: `npm.cmd test`.

## Обновление

Экспортировать прогресс из профиля предыдущей версии, остановить сервер, распаковать архив поверх существующей Git-папки с заменой файлов. Не удалять `.git`. Не менять порт 8001 или браузер: origin определяет доступ к сохранённым данным. Старый `content/catalog.js` не используется (удалён в 0.6). Схема прогресса 2 сохранена, добавлен необязательный черновик экзамена. Импорт заменяет весь прогресс после подтверждения, не объединяет копии.

После локальной проверки команды PowerShell выполнять по одной:

```powershell
git status
```
```powershell
git add -A
```
```powershell
git commit -m "Release v0.7.0 - Exam variants and course review"
```
```powershell

```

## Новые функции

- Память: очередь всех доступных карточек курса, по времени повторения, с названием исходного урока. Можно переключить на текущий урок или все его карточки. Интервалы остались 1, 3, 7, 14, 30 дней; при ошибке 10 минут.
- Контроль: по два варианта A и B по 6 заданий. Старый вариант A и его ID не изменены. Ответы раскрываются после завершения; использованный вариант больше не предлагается как независимый. Черновик сохраняется при выходе и переключении уроков; историю можно открыть из профиля. Порог 100%; освоение отмечается, если хотя бы один вариант пройден на 100%. Независимость основана на честном самостоятельном выполнении, не на технической блокировке доступа к подсказкам.
- Практика: добавлены по два задания с выбором одного ответа, прежние задания и ID сохранены. История и конструктор ИИ поддерживают оба типа. Всего 15 заданий практики и 24 контрольных предложения.

## Ограничения

Контент черновой. Новые примеры основаны на правилах о вводных словах академического справочника (§ 91, ссылка в уроках). Полной редакторской приёмки нет. Банк конечный: после двух вариантов новые независимые проверки требуют новых заданий. Регулируемый порог освоения, IndexedDB, PWA, автономные пакеты, синхронизация, полноценная версионная миграция изменённого контента ещё не реализованы. Не изменять содержание старых ID. Тесты Node с имитацией DOM не заменяют тест реального браузера на Windows.
