# БАЗА. Базируем. · Русский язык

Стартовая модульная сборка 0.4.0. Перенос прототипа 0.3 в исходные файлы без зависимостей и без сборщика. Не готовый PWA и не полный курс.

## Запуск

Из папки, где лежит `index.html`, выполнить `python -m http.server 8000` (Windows: `py -m http.server 8000`, если команда python не найдена). Открыть http://localhost:8000/ в браузере. Открытие index.html двойным кликом не поддерживается: браузер ограничивает ES-модули с file://. Для остановки сервера Ctrl+C. Для тестов нужен Node.js: `npm test` (установка пакетов не нужна).

## Структура

- `index.html` — оболочка; `src/styles/main.css` — утверждённое направление А+Б.
- `src/app.js` — контроллер, навигация и представления; `src/core/` — проверка, хранилище и генерация запроса ИИ.
- `content/` — каталог, учебные данные, карточки и хитрости, представление урока; далее вынести теорию в самостоятельный формат данных.
- `tests/` — автоматические проверки ядра; `docs/` — план следующих шагов.

## Ограничения

В первой сборке только один демонстрационный урок. Остаются локальное хранилище браузера (localStorage), фиксированный контроль из шести заданий, оценки карточек без алгоритма интервального повторения, экспорт без импорта. Прежний ключ хранения сохранён для того же origin; прогресс локального HTML не переносится автоматически на localhost. Не реализованы Service Worker, установка PWA, IndexedDB, загрузка пакетов уроков, полноценный банк экзаменационных заданий. Нормативная приёмка материала предстоит. UI и контроллер пока частично связаны, это промежуточная архитектура. React/Vite и TypeScript не отвергнуты: решение после проверки необходимости. Не публиковать до проверки и решения владельца.
