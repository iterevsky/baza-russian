# БАЗА. Ё. v0.49.0 — кандидат на приёмку

Исходный архив: BAZA_Russian_0480.zip. GitHub не изменялся и не проверялся. Эта версия не является заявлением о готовности стабильного релиза.

## Исправления

- Номер 0.47 в интерфейсе заменён на 0.49.0; подвал использует data-release. Добавлен регрессионный тест соответствия package.json. Уточнено устаревшее сообщение о четырёх языковых хитростях (теперь фактическое число); устранены двойной атрибут role и лишний закрывающий тег br.
- Начатое обучение определяется также по заметкам, попыткам, карточкам, экзаменам и черновикам, даже если первый урок не прочитан. Сброс всего курса возвращает начальный сценарий. Повторная отрисовка прочитанного урока не инициирует новую запись только из-за флага чтения.
- Интерфейс блокируется до асинхронного чтения импортируемого файла и остаётся заблокированным до окончания операции; это уменьшает риск навигации/параллельного сброса при импорте. Сообщение об ошибке имеет резервное место вывода. Существующие схемы хранения не изменены; сохранение и импорт по-прежнему используют сравнение ревизий.
- Мобильное меню закрывается при нажатии вне меню, смене ширины и Escape; Escape возвращает фокус. На коротких узких экранах уменьшены титульные интервалы и размер Ё; основная композиция сохранена.
- Service worker отвечает на запрос состояния текущего кеша. Интерфейс не показывает готовность только по наличию контроллера; проверяется наличие всех 277 ресурсов и соответствие версии. При неполном пакете доступно восстановление: только отсутствующие или неуспешные записи, с SHA-256 проверкой новых ответов, без удаления кешей и данных обучения. Восстановление не гарантирует проверку целостности каждой уже сохранённой записи; проверка наличия кеша не эквивалентна реальной офлайн-приёмке.

## Проверки

- 164/164 Node.js теста, строгий машинный аудит exit 0. Включены четыре новых теста (определение начатого обучения, номер версии, проверка комплектности кеша, восстановление недостающих записей). HTTP-тесты сверяют хеши всех 277 ресурсов; модели IndexedDB проверяют конфликт вкладок, отказ записи, миграцию и импорт. SW тесты проверяют отказ при неполной поставке, восстановление по контрольным суммам, изоляцию кешей и автономную отдачу на модели.
- Браузер Chromium: реальный localhost заблокирован ERR_BLOCKED_BY_ADMINISTRATOR. Отдельный стенд использует реальную разметку, CSS и контроллер, но подменяет хранилище на память и загрузку файлов на тестовый fetch; PWA на нём не исполняется. 176 состояний: 8 размеров 320–1440, 2 темы, 11 экранов (главная, каталог, практика, память, хитрости, журнал урока, прогресс, настройки, диагностика, урок, раскрытый очерк). Проверено горизонтальное переполнение и выход элементов за правую границу, ошибок JS не обнаружено. Это не доказательство отсутствия всех наложений или ошибок доступности. На отдельном стенде также проверены начало, продолжение, настройки, меню, полный сброс с подтверждениями и переход к диагностике.
- Учебные файлы: все 246 файлов уроков/модулей побайтово идентичны 0.48.0. 107 модулей, 139 уроков, 1008 практических заданий, 3996 экзаменационных вопросов с архивом, 5004 проверяемых ключа, 507 карточек, 163 открытых кейса, 73 языковые хитрости. Все прежние файлы сохранены.

## Блокеры стабильного релиза

- Локальная приёмка в настоящем браузере с IndexedDB, Cache Storage, установкой, перезагрузкой без сервера, импортом и конфликтом вкладок; проверка на физических телефонах и других браузерах. Выполнить сценарии docs/TECHNICAL_ACCEPTANCE.md. Chromium на стенде не заменяет эти проверки.
- 133 урока и 107 модулей имеют статус draft, 6 уроков reviewed. 43 зоны неполного охвата и 238 ключей «да/нет» (77 пунктуационных пропусков) остаются по инвентаризации 0.48.0; содержательная проверка каждой нормы, ключа, источника и независимая филологическая экспертиза не проводились. Строгий аудит не сертифицирует методическое качество. Статусы не повышены искусственно.
- Портрет Пушкина всё ещё не встроен локально; имеется ссылка на оригинал. Комплексная диагностика всего курса, жест открытия меню, общая страница платформы и полноценная адаптация объёма теории/практики остаются незавершёнными. Нормативные источники, лицензии и права на все материалы не прошли независимый полный аудит.
- До закрытия блокеров версия считается кандидатом на локальную приёмку, а не 1.0.0. Не удалять данные браузера для проверки, предварительно экспортировать прогресс.
