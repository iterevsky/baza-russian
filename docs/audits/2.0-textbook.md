# БАЗА. Ё. 2.0 — содержательная ревизия учебника

## Объём работ
- Сохранена теория четырёх пилотных уроков. Для остальных 135 написан новый объясняющий слой с конкретными примерами, введением понятий и вопросом с разбором. Полезные прежние специальные сведения сохранены после нового объяснения. Это не полная замена каждого абзаца прежнего учебника.
- 154 вопроса с раскрываемыми объяснениями (19 пилотных и 135 новых). 139 новых самостоятельных задач с образцами рассуждения и критериями самопроверки. Всего 302 открытых задания, включая 163 прежних.
- Сохранены 1008 практических заданий, 3996 экзаменационных вопросов с архивом, 507 карточек, 107 модульных файлов. Поштучная методическая проверка и переработка этих прежних контрольных банков не завершены.
- Переходы следуют учебной нумерации; уточнены семь текстовых связок. Служебные редакционные замечания вынесены в реестр. 43 унаследованных пробела охвата не объявлены закрытыми. Статусы источников и независимой экспертизы не повышены.

- 560 состояний автономного HTML для чтения: введение и 139 уроков в четырёх сочетаниях ширины, темы и глубины теории. Нет обнаруженных переполнений проверенных контейнеров и ошибок JavaScript. Это не исчерпывающая визуальная проверка и не приёмка установленной PWA. Проверены переходы, выбор урока и раскрытие объяснений.
- Проверки совместимости исторического прогресса и сохранности исходных оценочных материалов выполнены автоматическими тестами. Исторические проверки сохранены на снимках прежней редакции. Физические устройства и настоящее обновление PWA не проверены.

## Поставка
Накопительный патч поверх 1.1 или пилотной 2.0. Требуется локальная пересборка PWA с оригинальным портретом. Отдельный HTML для чтения не заменяет учебный движок, экзамены или сохранение прогресса. Независимая филологическая экспертиза не проводилась. GitHub не изменялся. Рекомендация: локальная приёмка перед публикацией; не обозначать курс как полностью экспертно проверенный.
