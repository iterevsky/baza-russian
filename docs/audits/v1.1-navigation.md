# Версия 1.1 — навигация и обновления
Публичный номер 1.1; внутренний npm/PWA 1.1.0. Редакционная проверка продолжается, номер не является свидетельством филологической экспертизы.
- Счётчики разделов: текстовое число с правильной формой «модуль/модуля/модулей», без рамок.
- История экранов, раскрытия разделов, меню и панели обновлений; на корне standalone предусмотрен защитный шаг, обычный браузер сохраняет право покинуть сайт.
- Контрольные результаты и черновики восстанавливаются из текущего хранилища, не из устаревшей истории. При отсутствии черновика возможен возврат к обзору. Несохранённый ввод практики при смене урока не гарантируется.
- Верхняя сворачиваемая панель обновлений. Существующая проверка целостности и безопасная активация пакета не изменены.
- 180 тестов, строгий аудит, 72 визуальных состояния двух проектов, 8 сценариев history.back в Chromium с моделью хранилища. Не проверено физическое системное действие Back, IndexedDB и реальное обновление PWA. Системный выход/закрытие приложения не контролируется сайтом.
- Патч не содержит портрета или сгенерированного sw.js: пересобрать с настоящим локальным JPEG. Учебные файлы не изменены.
