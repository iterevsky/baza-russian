# БАЗА. Русский язык — v0.41.0

## Объём
Исходник: BAZA_Russian_0400.zip. Репозиторий GitHub в этой итерации не проверялся и не изменялся. Первая содержательная ревизия 14 модулей 08.01–08.08, 09.01–09.06: индивидуальные цели, дополнительная теория, 14 разборов с самопроверкой и 14 письменных заданий. В каждом модуле два новых варианта по восемь вопросов (224 вопроса). 61 вопрос содержит дополнительные допустимые формулировки. Старые варианты архивированы. Существующие ID, ключи, статусы, редакторские кейсы и карточки сохранены. Обновлены номер версии и PWA.

80/107 модулей прошли первую ревизию. 27 модулей сохраняют двухвопросные варианты. Текущие варианты: 54 по 2, 156 по 8, 2 по 10, 2 по 16 вопросов.

## Открытые вопросы
35 из 224 новых экзаменационных заданий имеют бинарный ответ «да/нет»; часть остальных тоже предлагает выбор из двух слов. Это годится для базовой диагностики, но не доказывает перенос навыка на свободные тексты. Необходимо расширять самостоятельные редакторские задания и открытые исторические разборы, проверять смысловые повторы и равнозначные формулировки. Психометрическая независимость вариантов не доказана. Старые дефекты из реестра v0.34.0 остаются открыты в соответствующей части. Независимая филологическая экспертиза не проведена; материалы имеют статус draft. Допуска к публичному выпуску нет.
