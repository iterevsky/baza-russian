# Методическая переработка 2.0: первый рабочий пакет

Не публичный стабильный релиз. Рабочий образец для утверждения нового подхода. Введён экран «Введение», переписана основная и расширенная теория четырёх уроков раздела 01. В них 19 вопросов с раскрываемым объяснением (не оцениваются автоматически). Прочие 135 уроков пока прежние. Сохранены все 1008 практических и 3996 экзаменационных заданий, их ID, ответы, карточки и редакторские работы. Практика, экзамены и программа требуют дальнейшей содержательной ревизии; новое объяснение не означает новую экспертизу всего раздела.

Проверен исходный порядок всех 139 уроков, добавлены ссылки на предыдущий и следующий урок по программе, в конце теории, завершённой практики и результата экзамена. При первом входе с кнопки начала открывается введение; возвращающиеся учащиеся сохраняют текущий урок. Жест протягивания в конце урока проверен функцией порога, не на физическом телефоне. Исторический порядок хранения, версия учебных записей и ключи не менялись.

Машинный структурный скрининг исходника: 139 открытий с готовым примером; 121 урок содержит менее 250 слов в абзацах и правилах; 77 без явных prerequisites; 10 с конкретной редакторской пометой «Границы базового урока». Это сигналы для изучения, а не доказательства непригодности. Полная ручная экспертиза не проводилась. Из публичных источников выборочно сверены сведения о вариантном ударении (Грамота.ру), терминологическая основа (Литневская). Новые тексты — оригинальные учебные объяснения, не заимствованные главы.

Автоматические тесты: 183 из 184. Единственный непройденный тест требует оригинального JPEG `icons/pushkin-1827.jpg`, которого нет в локальной реконструкции. В патч изображение, sw.js и runtime-index.json не входят: на компьютере владельца следует сохранить оригинал и запустить npm.cmd run pwa:build, затем повторить весь набор тестов. Строгий машинный аудит прошёл (это не филологическая экспертиза). Пакет проверен с исходниками 1.1, основные файлы совпадают с GitHub по Git blob SHA. GitHub не изменён.

Chromium заблокировал прямой запуск localhost. Отдельный автономный HTML-образец использует настоящую разметку введения и новых уроков, CSS и собственную демонстрационную навигацию. 40 состояний, 4 ширины, 2 темы, без обнаруженного переполнения страницы и проверяемых компонентов. Проверены кнопки вперёд/назад и раскрытие объяснения и углубления. Не проверены физические телефоны, системная кнопка, жест в реальной PWA, браузерное хранилище и реальное обновление. Старый контроллер проверяется ранее существующими тестами с моделью DOM; новый порядок и сохранность данных — отдельными тестами.
