# БАЗА. Русский язык: v0.42.0

## Объём и совместимость
Исходник BAZA_Russian_0410.zip. GitHub не проверялся и не изменялся. Первая содержательная ревизия всех девяти модулей 10.01–10.09: индивидуальные цели, дополнительная теория, девять разборов с самопроверкой, девять новых письменных упражнений. В каждом модуле два новых варианта по восемь вопросов (144 новых экзаменационных задания). 15 вопросов имеют дополнительные допустимые ответы. В блоке склонения собственных имён проверяется также регистр букв. Старые варианты архивированы; прежние вопросы, ID, ключи, карточки и редакторские кейсы сохранены. 228 из 246 учебных файлов не изменились побайтово; 18 оригиналов сохранены в tests/fixtures/v041. Снимки прежних версий используются для исторических тестов, а новые проверки работают с текущим курсом. Движок оценивания не изменялся.

Первичная ревизия: 89/107 модулей. Активные контрольные варианты: 36 по 2 задания, 174 по 8, 2 по 10, 2 по 16. Двухвопросных модулей осталось 18. Учебные материалы сохраняют прежние статусы (133 draft, 6 reviewed).

Отдельно отмечены варианты количественного согласования и счётные формы единиц измерения. В новых вопросах нет бинарных ответов «да/нет», но часть заданий проверяет узнавание термина, простое формообразование или извлечение информации, а не перенос навыка на свободную речь. В частности, этикет и сложные речевые ситуации требуют самостоятельной редакторской практики. Перечни допустимых ответов не исчерпывают все возможные корректные формулировки.
