# v0.47.0 — главная курса и знакомство

Исходники: BAZA_Russian_0460.zip и утверждённый A_editorial_audited.html. В приложение перенесены десять глав предисловия, типографическая композиция А с SVG-буквой, обе темы и винный акцент. Все 107 модулей доступны из главной, значения счётчиков вычисляются из курса. Существующие экран урока, экзамены, карточки и редакторская лаборатория сохранены. Добавлены добровольный переход к диагностике по модулям, настройки запуска и раскрытия теории, рекомендация практики, статистика, полный/частичный сброс через существующий репозиторий с сохранением настроек, мобильное меню, сообщения о ходе загрузки PWA. Полный сброс требует двух подтверждений. Старый формат экспорта поддерживается; новые настройки сохраняются в схеме 2 с безопасными значениями по умолчанию.

## Проверки

- `npm test`: 158/158 (155 прежних + 3 новых). Строгий машинный аудит: код 0. 277 ресурсов PWA; существующие тесты проверяют их контрольные суммы, HTTP и модели автономности.
- Все 246 файлов уроков и модулей совпадают побайтово с 0.46.0; ни один файл из предыдущего архива не удалён. Ключи и идентификаторы не изменены.
- Chromium: 40 комбинаций от 320 до 1920 px, светлая/тёмная тема, первое/повторное посещение. Отрисовка HTML, сгенерированного текущим homeView с реальным индексом и CSS приложения, в документе Chromium; разделы и главы раскрыты. Проверены горизонтальное переполнение, границы выбранных заголовков и кнопок, пересечения шести пар ключевых элементов. По этим критериям 0 нарушений. Это не исчерпывающая проверка всех элементов. В четырёх комбинациях повторного входа кнопка продолжения ниже видимой части окна. Панель PWA и все динамические состояния не охвачены визуальной сеткой.
- Chromium, тестовый стенд UI: исходные модули приложения загружены через import map, fetch заменён локальной моделью реальных JSON, IndexedDB заменена репозиторием в памяти. Проверены главная, первый урок, возврат и продолжение, мобильное меню, настройка запуска, полный сброс с подтверждениями, входная диагностика. Ошибок JS в пройденном сценарии нет. Стенд `v0.47.0-ui-harness.py` предназначен для запуска из корня в среде Python/Playwright/Chromium. Это не тест реального хранилища, сетевого запуска, перезапуска или PWA.

## Ограничения и оставшиеся задачи

- Chromium блокирует `http://localhost:8001/` (`ERR_BLOCKED_BY_ADMINISTRATOR`), даже с перехватом маршрута. Реальная Windows/Android/iOS/Firefox/Safari-приёмка, установление ярлыка, offline-перезапуск и проверка записи в реальную IndexedDB остаются открытыми.
- Портрет Кипренского не скачан из-за DNS-ограничения; вместо пустой рамки показана типографическая композиция и ссылка на внешний источник. Встроить локальный портрет перед выпуском.
- Диагностика работает по существующим модульным экзаменам; единого отдельного входного теста на весь курс нет. Предпочтение теории/практики не меняет состав заданий, оно сохраняется и для практического режима даёт дополнительный переход. Настройка расширенной теории работает как режим раскрытия имеющихся блоков. Жестовое открытие мобильного меню не реализовано. Общий каталог платформы ещё не создан, переход к нему не добавлен.
- Статистика по урокам и разделам использует действующие критерии экзаменов; история активности показывает последние десять записей. Модель прогресса и банки упражнений не пересматривались в этой итерации. Остаются методические замечания 0.46.0, независимая филологическая экспертиза не выполнена.
- GitHub не проверялся и не менялся. v0.47.0 — кандидат на локальную приёмку, не 1.0.0.
