## Проверки
- `npm test`: 153/153; 4 новых теста на HTTP-отдачу всех 274 ресурсов и проверку хешей, ограничения HTTP, gzip, восстановление фокуса. Исторические тесты не изменялись.
- `npm run audit`: код 0; `node scripts/audit-quality.mjs --strict`: код 0. 107 модулей, 139 уроков, 926 практических заданий, 3980 экзаменационных (включая архив), 507 карточек, 163 открытых кейса; прежние ключи не менялись.
- PWA: 274 ресурса, SHA-256 каждого ответа после декодирования совпадает со сгенерированным manifest в sw.js. Модель service worker проверяет установку, отказ при неполном обновлении, изолированность кешей, офлайн-ответы и восстановление идентичных ресурсов.
- Доступность: проверено на уровне кода, теста фокуса и CSS, не WCAG-сертификация.
- Хранилище: регрессионные тесты IndexedDB и localStorage используют тестовые модели; реальный профиль браузера не проверен. Формат прогресса неизменен.
- Chromium с viewport 320×720 запущен, но навигация к 127.0.0.1:8001 отклонена `ERR_BLOCKED_BY_ADMINISTRATOR`; управляемая браузерная политика запрещает URL. Обход ограничений не выполнялся. Реальный рендер, PWA, мобильный интерфейс, IndexedDB и доступность остаются открытыми. Публичный выпуск не разрешён.

## Локальная приёмка
См. `docs/TECHNICAL_ACCEPTANCE.md`. Это обязательные проверки, а не уже полученные результаты. Не очищать данные сайта; сначала сделать экспорт. Если PWA показывает старую версию, закрыть все вкладки/окна приложения и открыть снова после завершения загрузки новой версии. Не менять порт и hostname.
