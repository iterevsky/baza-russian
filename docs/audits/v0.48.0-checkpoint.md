# БАЗА. Ё. v0.48.0: методическая ревизия

Исходник: BAZA_Russian_0470.zip. Главная страница, предисловие и CSS не перерабатывались. Версия кандидата, не стабильный релиз.

## Проверенные изменения

- Инвентаризация 139 уроков и 107 модулей; сравнение всех 246 учебных файлов с исходным архивом. 101 файл урока и один файл модуля изменены; 144 сохранены побайтово. Исходники изменённых файлов находятся в tests/fixtures/v047. Все 246 контрольных сумм проверены тестом.
- 82 новых задания (два в каждом из 41 урока, ранее имевших по пять заданий). Всего 1008 упражнений, во всех уроках не менее шести. Это минимальный количественный показатель, не критерий достаточности. Некоторые задания с двумя предложенными вариантами и коротким ответом остаются относительно простыми; они не считаются независимым доказательством переноса навыка.
- 59 предметных дополнений к рубрикам. Все 163 редакторских кейса имеют не менее трёх критериев; число критериев само по себе не гарантирует полноценности. В образце про двусмысленное слово «ключ» устранено неподтверждённое добавление факта, что ключ оставили на площадке.
- 12 дополнительных объяснений и самопроверок: 04.02, 04.03, 04.05–04.08, 06.01, 06.04, 06.07–06.09, 07.13. Точечная сверка корней, разделительных знаков и оформления прямой речи по справочным материалам; ссылки добавлены в соответствующие уроки. Прежние 43 указания на неполный охват оставлены, поскольку ни один такой пробел не считается закрытым полностью без дальнейшего анализа.
- Научная этимология (09.06): два новых варианта по 8 вопросов. Прежние варианты архивированы, их ключи, версии и IDs сохранены. Девять ключей да/нет заменены активными заданиями с кратким предметным ответом; часть вопросов по-прежнему содержит варианты ответа. Старые завершённые результаты и черновики успешно импортируются и могут быть завершены. Для нового контроля требуется новая попытка. Уроковые экзамены и их условия освоения не изменены.
- 238 активных ключей да/нет (было 247), в том числе 77 задач с пропуском □, где «нет» означает отсутствие знака. Остальные 161 — сигнал для ручной проверки: не все являются бинарными утверждениями (например, «нет» для исчезновения гласной). Не следует механически менять пунктуационные задачи лишь ради устранения слова «нет».
- 16 новых экзаменационных вопросов; 3996 вопросов с архивом; 5004 проверяемых ключа. 214 активных модульных вариантов, минимум 8 вопросов. 507 карточек, 163 открытых кейса, 277 ресурсов PWA. Все старые уроковые задания и ключи сохранены. 20 карточек с альтернативами остаются для содержательной оценки.

## Техническая проверка

160/160 тестов, строгий машинный аудит exit 0. Проверены исторические хеши, сохранность прежних ключей, импорт 926 записей старой практики, завершённой попытки и черновика 09.06, прохождение двух новых вариантов, работа новых ключей. Исторические регрессионные тесты используют снимок соответствующей версии; добавлены две проверки актуального содержимого и импорта. PWA индекс перестроен. Архив проверен на целостность и наличие исходных файлов.

## Границы

Это содержательная доработка и сквозная машинная диагностика, не полная ручная проверка всех норм, всех ответов и всех источников. 43 отмеченных зоны неполноты требуют отдельной работы, как и часть простых вопросов. Независимая филологическая экспертиза не проводилась. Реальные браузер, мобильное устройство, офлайн и визуальная приёмка в этой версии не проводились. Локальный портрет Пушкина, комплексная входная диагностика, жесты и прочие известные задачи 0.47 не закрыты. GitHub не изменён. Статусы материалов не повышены. Следующая версия 0.49: финальная доработка и приёмка, без автоматического допуска к 1.0.
