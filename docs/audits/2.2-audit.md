# БАЗА. Ё. 2.2 — результаты проверки

База: точный накопительный архив 2.1 из библиотеки. Публичный репозиторий на момент проверки package.json показывал 2.0.0. Патч 2.2 объединяет изменения 2.1 и текущие изменения, не меняет удалённый репозиторий.

## Выполнено

1. Исправлены правила цвета `select`, `option`, `optgroup`, полей `.search`, placeholder и `color-scheme` для выбранной темы. Источник ошибки — отсутствие явного цвета у общего select при заданном фоне `.search`.
2. 109 новых карточек хода решения в 109 уроках, сохранены все 139 схем 2.1. Четыре новых письменных задания. Новые поля и блоки валидируются; пользовательский текст экранируется. ID старого контроля не изменены.
3. Сравнение всех 139 JSON с 2.1: после удаления нового блока theory совпадает; прежние открытые задания совпадают, все остальные поля совпадают. Данные в старых проверках не изменились. Сводка `2.2-data.json`.
4. Три новых целевых Node-теста прошли. Проверены 109 моделей, порядок перед схемой, 139 уникальных схем, экранирование, наличие 458 уникальных открытых работ. Проверка синтаксиса трёх изменённых JS-модулей прошла.
5. Chromium: форма из разметки настроек `src/app.js` плюс пример сброса, поиск и поле ответа. 6 сочетаний ширины 320/390/1440 и светлой/тёмной темы. Проверены вычисленные цвета всех select/option/optgroup/input/textarea, минимальная контрастность 11.10:1, переключение значения select, отсутствие переполнения. Нативное всплывающее меню мобильного Safari и Android не испытано.
6. Автономный читательский HTML 2.2: 560 состояний (140 страниц × четыре сочетания ширины, темы и глубины), нет обнаруженных переполнений проверенных компонентов, ошибок JavaScript; выбор урока, раскрытие решения и сохранение черновика внутри открытой вкладки проверены. Это не полная проверка визуальной композиции всех экранов и не тест установленной PWA.

## Ограничения

Доступная локальная основа является накопительным патчем, а не полным репозиторием: каталог, 107 модульных файлов, исходные контроллеры и сценарий сборки PWA отсутствуют. Сетевое скачивание полного архива репозитория недоступно. Поэтому полный `npm test`, строгий аудит и сборка PWA в текущем окружении не выполнялись. Не переносить результаты 2.1 на 2.2 как новые испытания. Пользователь должен выполнить их на полной локальной копии. Сохранность старых данных проверена сравнением JSON, а не реальным обновлением PWA. Исходный портрет Пушкина не включён и не заменяется. Сборка не содержит сгенерированных `sw.js` и `content/runtime-index.json`: обязательна пересборка перед публикацией. Не проведена независимая филологическая экспертиза или проверка на реальных учащихся. Диктант требует помощника; аудиодиктант и полный новый банк независимых экзаменов не реализованы.
