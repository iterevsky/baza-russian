# БАЗА. Русский язык: v0.46.0 — методическая доработка и готовность к приёмке

Исходник: BAZA_Russian_0450.zip. Репозиторий и компьютер пользователя не проверялись, GitHub не изменялся. Это промежуточная сборка, не допуск к 1.0.0.

## Изменения
- 64 карточки с предложенными альтернативами превращены в вопросы на самостоятельное воспроизведение; ответы, ID и порядок сохранены. Оставшиеся 20 карточек с разделителем содержат сопоставления, пары слов или классификации; их нельзя автоматически считать дефектными.
- Для 40 открытых работ дополнены рубрики конкретными критериями, привязанными к условию. Не менялись ID, текст задачи и образцы решений.
- Добавлены два теоретических уточнения: приставки раз-/роз- и отрицание с причастиями/наречиями. Сверены доступные материалы ИРЯ РАН (https://oross.ruslang.ru/paragraph/25) и Грамоты (https://gramota.ru/biblioteka/spravochniki/pravila-russkoy-orfografii-i-punktuatsii/razdelnoe-napisanie-ne). Это точечное расширение, не закрытие всего раздела. Предыдущие предупреждения о неполноте не удалены.
- Обновлены версия интерфейса, package.json и PWA. Исходные учебные файлы, затронутые редактурой, сохранены в tests/fixtures/v045. Две исторические проверки используют снимок v0.45 для проверки прежних изменений; новые тесты сравнивают актуальный курс с этим снимком, не ослабляя проверку ключей.

## Проверки
- npm test: 155/155, включая прежние HTTP/PWA-тесты, новый контроль неизменности всех оценочных банков, ответов и идентификаторов, сохранение карточек и рубрик, импорт старой истории карточек в полном и компактном индексе.
- node scripts/audit-quality.mjs --strict: код 0. 107 модулей, 139 уроков, 926 практических, 3980 экзаменационных (включая архив), 507 карточек, 163 кейса. 214 активных модульных вариантов, минимум 8 заданий.
- Методическая диагностика: карточки с разделителем 84 → 20; рубрики с ≤2 критериями 99 → 59. Бинарные активные вопросы 247 → 247; уроки с ≤5 упражнениями 41 → 41; уроки с явным пробелом охвата 43 → 43. Сигналы не эквивалентны доказанным ошибкам; число критериев не является мерой их полноты.
