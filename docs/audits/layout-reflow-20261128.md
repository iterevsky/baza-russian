## Исходник и исправления

Исходные `src/core/home.js`, `src/styles/home.css`, `src/styles/main.css`, `src/app.js`, `src/core/catalog-ui.js`, `index.html` сверены с GitHub main по blob SHA. Применён небольшой патч к существующему RC1 с предыдущими обновлениями. Платформа не изменена.

- Номера глав и модулей неразрывны; колонка рассчитывается по размеру содержимого, а не по прежней ширине 28 px. Счётчики модулей и числовые обозначения защищены от разрыва.
- Карта знаний использует реальную ширину контейнера, одну колонку при недостатке места, равную ширину и высоту карточек, внутренние поля. Описание не набирается прописными. В длинном слове «словообразование» предусмотрен мягкий перенос после «слово».
- Литературный очерк имеет один заголовок и самостоятельное раскрытие текста. Остальные девять глав заново пронумерованы I–IX; их технические идентификаторы сохранены. Все десять исходных HTML-статей побайтово совпадают после извлечения из разметки; учебные файлы не менялись.
- Общие ограничения размеров и переносов применены также к урокам, упражнениям, карточкам, панелям, таблицам, статистике и другим контейнерам. Переполнение не маскируется `overflow:hidden`. Вместо повёрнутого плюса в открытых главах используется минус.

## Ограничения и установка

Настоящий контроллер, локальное содержание и CSS выполнялись в Chromium посредством тестовой сборки ES-модулей, модели загрузки файлов и локального хранилища. Открытие HTTPS блокируется политикой окружения. Реальные мобильные браузеры, PWA и оригинал портрета не проверены. Для Node-тестов использовался временный JPEG; он не включён в патч. `sw.js` и оригинальный JPEG также не включены: после распаковки необходимо выполнить `npm.cmd run pwa:build` на устройстве, где сохранён оригинал, затем `npm.cmd test` и строгий аудит. Формат прогресса, учебный движок, оценивание и тексты не изменены. GitHub не изменялся.
