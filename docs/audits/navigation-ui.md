# БАЗА. Обновление интерфейса 0.4 / русского языка

- Платформа: кликабельное название курса с тем же проверяемым URL, расширенный раздел «От автора», отдельные блоки каталога и манифеста, мобильное модальное меню, скрыта предварительная версия в карточке.
- Русский язык: открытый путеводитель перед литературным предисловием, ссылки в настройки, программу, диагностику, ИИ-конструктор и прогресс. Номер/название модуля, отдельная кликабельная строка урока и второстепенная ссылка экзамена. Группированное мобильное модальное меню; начало обучения с 01.01 при отсутствии прогресса, продолжение прежнего урока. Сведения о версии в сворачиваемом блоке.
- 246 файлов уроков и модулей побайтово совпадают с RC1. Формат хранения не изменён.
- Тесты: 175/175 русского языка, 7/7 платформы. Строгий аудит прошёл. Старый тест каталога адаптирован к отдельным HTML-элементам номера и названия, проверки содержания и переходов сохранены.
- Визуальный стенд Chromium: 130 состояний, 9 ширин 320–1440, две темы, базовый текст 100/200%, раскрытие и Escape для мобильных меню. После исправлений 0 горизонтальных выходов в проверенных состояниях, 0 JS-ошибок стенда. Проверка выполнена на разметке, сформированной настоящим контроллером с моделями хранилища, не на опубликованном сайте.
- Прямое открытие HTTPS в Chromium заблокировано ERR_BLOCKED_BY_ADMINISTRATOR. Реальная мобильная установка, PWA-обновление и физические устройства не проверены. JPEG оригинала недоступен в контейнере; тесты проведены на временном JPEG, который не входит в патч. Русский service worker необходимо пересобрать на устройстве пользователя, где есть оригинал.
- Публичная метка RC убрана из карточки платформы и заголовка курса, техническая версия RC1 сохранена. Независимая филологическая экспертиза не завершена.
