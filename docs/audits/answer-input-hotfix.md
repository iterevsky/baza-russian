Исходник: RC1 с UI-патчем. Список из 1810 идентификаторов построен консервативным фильтром по типу, содержанию и разделу (265 практических, 593 поурочных экзаменационных, 952 модульных, включая архивные). В этих заданиях регистр, одиночная точка в конце и лишние пробелы не влияют на оценку. Допустимые формы ответа о языковой семье добавлены отдельно для двух вопросов. Другие синонимы автоматически не угадываются; ошибочное написание, ё, внутренние знаки и формы слов не заменяются произвольными. Разделы орфографии и пунктуации исключены из нового списка. Исходные правила строгого оценивания сохранены для остальных заданий. Инструкции исправлены без удаления смысловых требований. Выбор списка эвристический, не сплошная филологическая экспертиза. Старые корректно сохранённые результаты принимаются по прежней или новой проверке и пересчитываются; новая оценка не снижает прежнюю. Контент и runtime-index побайтово неизменны.
