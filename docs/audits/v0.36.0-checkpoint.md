# v0.36.0 — орфография: первая содержательная ревизия

**Частная тестовая сборка; не публичный выпуск.** Исходная сборка v0.35.0. Из запланированных 40 модулей в этой версии содержательно доработаны 14 (06.01–06.14). Синтаксис (12) и пунктуация (14) получили структурную инвентаризацию и перечень точек для проверки; их содержательная переработка перенесена на следующий этап, чтобы не имитировать качество.

## Реализовано

- 14 расширений теории: условия применения, исключения, индивидуальные цели. 28 письменных упражнений, 224 новых задания модульного контроля (два варианта по восемь на каждый модуль). Не все подтемы исчерпаны, вопросы преимущественно письменные, а не открытые диктанты; уроковые экзамены, карточки и прежние ключи не изменены.
- Старые 28 орфографических вариантов (56 заданий) архивированы, не удалены: можно завершать прежний черновик, импортировать историю, повторять раскрытые задания. В новом контроле доступны только новые варианты. Интерфейс явно отличает архивный результат от актуального.
- В `start.bat` добавлена предварительная проверка привязки порта 8001. При конфликте выводится понятная диагностика и команда поиска PID. Процессы не останавливаются автоматически, порт не меняется. Возможна гонка между пробой и запуском; исполняемый BAT в Windows здесь не запускался.
- 218 из 246 прежних учебных файлов побайтово неизменны. 28 файлов изменены намеренно: 14 уроков и 14 паспортов модулей. Исходники сохранены в тестовых фикстурах, старые ID, версии, порядок и ключи проверяются отдельно. Исторические тесты хешей читают исходные байты изменённых файлов; проверка текущих данных остаётся активной.
