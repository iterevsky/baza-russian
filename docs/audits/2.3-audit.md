# БАЗА. Ё. 2.3 — методические ступени и учебные зависимости

## Изменения
- Карта 139 уроков в учебной последовательности из читательского HTML 2.2: 138 уроков имеют предварительные темы, первый урок не имеет. 76 ранее пустых списков заполнены; 274 связи в сумме. Все связи направлены к более ранним занятиям. Это авторская модель предварительных знаний, не доказательство исчерпывающего охвата каждого термина. Ссылки доступны в начале урока, не блокируют свободное изучение.
- 56 авторских ступеней в 28 уроках; существительное — 6, глагол — 8, причастия и деепричастия — 4. Отдельные задания на выделение основы, полного сказуемого и подлежащего; противопоставление грамматических конструкций и выбор написания. По одному короткому смешанному заданию в последнем уроке каждого раздела. Это тренировочные задачи с обратной связью, а не независимые экзамены. Результаты ступеней живут в открытом уроке, сохраняются при переключении глубины теории внутри него; после выхода не сохраняются и не влияют на оценки.
- Дополнительная карточка урока об уровнях языка, требующая терминов морфологии, спрятана в явно обозначенный необязательный блок. Теория, задачи и ID всех 139 уроков сохранены, кроме метаданных prerequisites. Не изменялись контрольные ключи, версии уроков, карточки, открытые работы. Не выполнена полная поэлементная ревизия прежних контрольных банков.
- Синтаксические деревья (4): сохраняются два главных узла на телефоне, линия идёт от сказуемого, зависимые карточки снабжены явным заголовком. Сегментация слова «переписка» добавлена в урок морфемики. Остальные 139 исходных схем не заменены универсальными новыми типами.
- Три размера текста, отдельная локальная настройка (не в резервной копии прогресса); сохраняется на устройстве, если доступен localStorage. В основном приложении раскрытие теории компенсирует изменение положения кнопки, в автономном HTML сохраняется позиция прокрутки.

## Испытания
- 7/7 целевых Node-тестов: 4 новых и 3 прежних 2.2. Проверены метаданные, структура/ключи 56 ступеней, независимость настройки шрифта, экранирование, визуальная структура схем, старые 139 схем и 458 открытых работ. Сравнение JSON всех 139 уроков с 2.2: ID, версия, theory, practice, exam, examVariants, cards и editorialCases совпадают.
- Chromium: 700 состояний (139 уроков + введение, 5 сочетаний ширины 320–1440, темы и размера шрифта; включая 320/dark/extra); все details и все ступени раскрыты для проверки. Нет переполнений проверенных элементов и ошибок JavaScript. Проверены ошибочный/верный ответ, повтор, переходы назад/вперёд, сохранение шага при переключении глубины, переход к предварительному уроку и смена размера. Скриншоты и JSON отдельно.
- Локальная копия 2.2 является неполным накопительным патчем. В ней отсутствуют части исходного репозитория, каталог, модульные банки и сборщик PWA. Полный npm test, строгий машинный аудит и реальный запуск опубликованной PWA не подтверждены; их необходимо выполнить в рабочей копии. GitHub не изменялся.

## Следующие критерии приёмки
- Довести все остальные уроки до последовательности объяснение → управляемое действие → независимое действие; не считать 56 ступеней окончательным решением.
- Создать матрицу школьных требований с проверенными первоисточниками и отдельными критериями сформированности навыков; закрыть пробелы программы. Сопоставление в EDUCATION_2.3.md является внутренней рабочей картой, а не сертификацией соответствия.
- Новые независимые варианты экзаменов без очевидных отвлекающих ответов, смешанные задания, анализ письменных работ, повторение навыков по времени. Новые контрольные ключи с новыми ID; сохранить историю предыдущих результатов. Провести независимую филологическую экспертизу и испытание на учащихся.
