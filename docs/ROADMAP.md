# Следующие этапы

1. Приватный репозиторий `baza-russian`, загрузка стартовой сборки, локальный запуск и проверка владельцем.
2. Стандарт данных темы: постоянные ID, версии, теория как данные, связи, источники, упражнения и критерии проверки.
3. История попыток и миграции в IndexedDB; импорт с валидацией, резервные копии; настраиваемый критерий освоения, независимые варианты экзаменов.
4. Адаптивное повторение, журнал ошибок, отдельные шаблоны упражнений, конструктор запросов с предпросмотром.
5. PWA: manifest, service worker, версионные пакеты, автономное использование после загрузки, безопасное обновление после урока.
6. Первый полноценный модуль вводных слов: редакторская и нормативная проверка, тесты телефона и компьютера, расширение контента.

Не добавлять тяжёлые движки аналитики в русский язык. Общее ядро выделять по фактическим потребностям второго приложения. Разработка приватная, публичный релиз отдельно.
