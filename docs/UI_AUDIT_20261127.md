# БАЗА. Визуальная ревизия двух проектов

**Платформа 0.3.2 / Русский язык 1.0.0-rc.1 (UI patch).**

## Изменения

Платформа: разделены уровни навигации, нумерация разделов удалена из надзаголовков, статусы отделены, карточки разделены пространством и рамками, знаки приведены к общему SVG-холсту 120×145 и близкой высоте рисунка (~110 единиц), шахматная полоска удалена, установка перенесена в нижнюю часть страницы. «Доступен» относится к доступности курса, а не к независимой экспертизе RC1. Палитра скорректирована в обеих темах.

Русский: центрирование знака по геометрическим границам; сокращены пустоты; убрана дублирующая ссылка рядом с эпиграфом, название очерка остаётся в оглавлении; отдельные границы глав и модулей; количество модулей в отдельной колонке; на мобильных экранных ширинах метаданные программы под заголовком; изображение в обычном потоке, без абсолютного позиционирования и обрезки; при ошибке загрузки отображается объяснение и ссылка. Логотип БАЗА. в боковой панели и футере ведёт на платформу. Панель автономности перенесена в сворачиваемый футер. Утверждённый текст всех десяти глав и 246 учебных файлов не изменены.

## Проверки

96 состояний: 12 ширин 320–1920 px × 2 темы × 2 режима базового размера текста × 2 сайта. На русском стенде открыты выбранные главы и разделы; на платформе раскрыта инструкция установки. Текстовые прямоугольники, горизонтальные границы и внутреннее переполнение проверены программно. На первом прогоне увеличенный текст выявил тесные метрики, римские цифры и скрытую ссылку пропуска навигации; после исправлений 96/96 без найденных нарушений. Проверены скриншоты. Ошибок JavaScript в этих проверках не обнаружено. Тест отказа загрузки изображения прошёл. Платформа: 4/4 тестов, русский: 169/169, строгий аудит успешен. 11 ресурсов платформы, 280 ресурсов курса в тестовой сборке.

## Ограничения

Chromium блокирует localhost; проверка проведена прямой загрузкой HTML и CSS, с настоящим выводом homeView и тестовой моделью навигации/статуса автономности, а не полноценным подключением реального приложения. Увеличение базового текста на стенде не идентично системному масштабированию iOS/Android. Firefox, Safari, физические телефоны и развёрнутые сайты не проверены. GitHub подтвердил наличие файла портрета и его SHA-256 в сводке service worker; получение бинарного файла в среде не удалось. Для проверки вёрстки, сервера и кеширования использовано явно тестовое JPEG. В патче отсутствуют JPEG и sw.js курса; сборка sw.js на компьютере владельца обязательна, с фактическим оригиналом. Причина мобильного сбоя не доказана. Не очищать данные сайта ради обновления. GitHub не изменялся.
