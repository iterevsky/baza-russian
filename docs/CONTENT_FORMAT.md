# Формат учебных материалов v1

`content/catalog.json` содержит `schemaVersion`, `courseId`, массив разделов (`id`, `title`, `moduleCount`, `description`, `lessons` с ID, относительным JSON-файлом и статусом). `content/tips.json` содержит самостоятельные языковые хитрости. `content/lessons/introductory-words.json` — первый образец урока: стабильные ID урока, модуля, раздела и элементов, версия, цели, связи, источник, контекст ИИ, теория, практика, карточки, контроль. Статус `draft` не равен опубликованному уроку.

Поддерживаемые блоки теории: heading, paragraph, rule, example, steps, examples, tip, deep. Только данные, никаких HTML/JS в текстах. Текст экранирует шаблон. Контроль: exact-text, практика: comma-positions. Форматы проверяет `src/core/content.js`; после каждого изменения `npm test`. Загрузчик читает JSON по HTTP и проверяет соответствие каталогу. Не изменять ID опубликованного элемента; при изменении смысла или эталона повышать версию. Текущая сборка оставляет прежние индексы для совместимости, поэтому не менять порядок имеющихся упражнений и карточек до миграции. Переключение между несколькими уроками, расширенные проверки связей, полноценная миграция истории, регулируемый порог, банк проверочных серий и нормативная приёмка остаются следующими этапами.
