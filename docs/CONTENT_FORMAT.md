# Формат учебных материалов v1

`content/catalog.json` содержит `schemaVersion`, `courseId`, массив разделов (`id`, `title`, `moduleCount`, `description`, `lessons` с ID, относительным JSON-файлом и статусом). `content/tips.json` содержит самостоятельные языковые хитрости. `content/lessons/introductory-words.json` — первый образец урока: стабильные ID урока, модуля, раздела и элементов, версия, цели, связи, источник, контекст ИИ, теория, практика, карточки, контроль. Статус `draft` не равен опубликованному уроку.

Поддерживаемые блоки теории: heading, paragraph, rule, example, steps, examples, tip, deep. Только данные, никаких HTML/JS в текстах. Текст экранирует шаблон. Контроль: exact-text, практика: comma-positions. Форматы проверяет `src/core/content.js`; после каждого изменения `npm test`. Загрузчик читает JSON по HTTP и проверяет соответствие каталогу. Не изменять ID опубликованного элемента; при изменении смысла или эталона повышать версию. В v0.6.0 два урока в каталоге; история сопоставляется по стабильным ID, прежние индексы мигрируют только в исходный урок. Загрузчик проверяет уникальность ID элементов курса и существование связей. Прогресс schema 2 содержит тему оформления, избранное, активный урок и byLesson с попытками, отметками карточек, экзаменами и конспектом. Импорт schema 1 и 2 поддерживает совместимые записи, несовместимые записи импорта отклоняются. Порядок и смысл существующих заданий нельзя менять без разработки версионной миграции; не менять ID. Регулируемый порог, независимые проверочные серии и нормативная приёмка остаются следующими этапами.

## Дополнения v0.7.0 (обратно совместимые)

- `exam` остаётся вариантом A. Необязательный `examVariants` — массив дополнительных вариантов с тем же форматом (`id`, `version`, `threshold`, `questions`). У каждого варианта и задания отдельный ID. Тексты контрольных предложений не должны повторяться между вариантами или в практике расстановки запятых. Старые ID и порядок не изменены.
- `practice` поддерживает `single-choice`: `id`, `type`, `prompt`, `options` (массив строк), `expected` (массив с единственным индексом правильного варианта), `ex`. В истории `selected` содержит индекс выбранного ответа. Новый тип добавляется после старых заданий.
- Схема прогресса 2: необязательный `examDraft` в данных урока (`examId`, `version`, `index`, `answers`) сохраняет незавершённую попытку. Завершённые варианты идентифицируются по `examId`; результаты прежнего A сохраняются. Импорт проверяет совместимость истории и черновиков.
