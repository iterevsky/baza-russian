# Портрет Пушкина для БАЗА. Ё.
Распакуйте в корень baza-russian RC1, сохраняя .git. Экспортируйте прогресс. Закройте вкладки курса и остановите сервер.
Запустите `node scripts/add-pushkin.mjs` в корне проекта. Скрипт скачивает оригинал Кипренского с Wikimedia Commons, проверяет JPEG, меняет только разметку портрета и правила выдачи изображения локальным сервером, сохраняет сведения об источнике и пересобирает автономный пакет. При ошибке сети вручную скачайте оригинал https://upload.wikimedia.org/wikipedia/commons/5/56/Kiprensky_Pushkin.jpg и сохраните как `icons/pushkin-1827.jpg`, затем повторите команду. Не публикуйте до успешной сборки и визуальной проверки. Прогресс и учебные материалы не затрагиваются. Проверено на временном синтетическом JPEG, который НЕ входит в этот архив. 167/167 тестов, строгий аудит, HTTP MIME и хеш файла прошли в тестовой копии. Реальный портрет не скачан в среде подготовки. После публикации закройте все вкладки и установленные окна курса, откройте заново при наличии сети, дождитесь обновления. Не очищайте хранилище сайта.
