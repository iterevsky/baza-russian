# БАЗА. Ё. 2.0 — установка накопительного обновления

Архив накладывается поверх версии 1.1 или пилотной 2.0. Это обновление, а не самостоятельный полный репозиторий. Экспортируйте прогресс, закройте приложение и остановите сервер. Сделайте резервную копию папки проекта. Распакуйте архив с заменой файлов в `D:\Users\User\Desktop\baza-russian`, сохраняя `.git` и оригинал портрета `icons/pushkin-1827.jpg`.

```powershell
cd "D:\Users\User\Desktop\baza-russian"
Test-Path .\icons\pushkin-1827.jpg
npm.cmd run pwa:build
npm.cmd test
node scripts/audit-quality.mjs --strict
.\start.bat
```

Проверка портрета должна вернуть True. Пересборка обязательна: генерируемые sw.js и runtime-index.json намеренно исключены из патча, поскольку они должны учитывать оригинальный JPEG. В рабочей среде прошло 183 из 184 тестов; оставшийся тест не выполнен из-за отсутствия JPEG. Проверьте результаты на собственном устройстве, прежде чем отправлять обновление на GitHub. Предыдущие контрольные банки сохранены, а не полностью переработаны. Независимой филологической экспертизы не было. Не представлять сборку как окончательно экспертно принятую.
