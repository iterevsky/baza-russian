# Локальный методический пилот 2.0
Не отправляйте на GitHub до полной переработки. Создайте отдельную копию рабочей папки baza-russian 1.1, без изменения опубликованной версии. Сохраните оригинальный icons/pushkin-1827.jpg и резервную копию прогресса. Распакуйте с заменой файлов в копию. Запустите npm.cmd run pwa:build, npm.cmd test, node scripts/audit-quality.mjs --strict и .\start.bat. Открывайте локальную копию на отдельном порту, чтобы не смешать браузерное хранилище. Не удаляйте историю и исходный репозиторий.
